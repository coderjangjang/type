# TYPE

설치나 빌드 없이 브라우저에서 바로 쓰는 **단일 HTML 파일** 타자연습 앱입니다.
한글·영어 연습, 실시간 타수/정확도 측정, 기록 그래프, 테마·효과음 설정을 지원합니다.

- 외부 라이브러리·네트워크 요청 없음 (HTML + CSS + 바닐라 JS 한 파일)
- 모바일(세이프 에어리어 대응) / 데스크톱 반응형
- 한국어·영어 인터페이스 (브라우저 언어에 따라 자동 선택)

## 시작하기

`index2.html` 파일을 브라우저에서 열면 끝입니다.

```bash
# 방법 1: 파일을 더블클릭하거나 브라우저로 드래그

# 방법 2: 로컬 서버로 실행
python3 -m http.server 8000
# → http://localhost:8000/index2.html
```

정적 호스팅(GitHub Pages, Netlify 등)에 파일 하나만 올려도 동작합니다.

## 주요 기능

### 연습 모드

| 모드 | 설명 |
| --- | --- |
| 짧은 글 | 문장 하나를 입력합니다 (직전 문장은 반복되지 않음) |
| 긴 글 | 문장 4개를 이어서 입력합니다 |
| 단어 | 단어 12개를 입력합니다 |
| 30초 / 60초 | 제한 시간 동안 단어를 계속 입력합니다 (글이 끝나기 전에 자동으로 이어짐) |

타자 언어는 **한글 / English** 중에서 메인 화면에서 바로 전환할 수 있습니다.
속담, 격언, 일상 문장, 단어 목록이 내장되어 있고, 같은 단어가 연속으로 나오지 않도록 섞어서 출제합니다.

### 실시간 통계

- **타수 (CPM)**: 분당 정타 수. 한글은 자모 분해 기준으로 계산합니다 (겹모음·겹받침은 2타).
- **WPM**: 맞게 친 글자 수 ÷ 5 ÷ 경과 분
- **정확도**: 확정된 글자 중 맞게 친 비율
- **시간**: 경과 시간 (타이머 모드에서는 남은 시간)

### 결과 화면 & 기록

- 종료 시 타수 / WPM / 정확도 / 시간과 **가장 많이 틀린 글자 TOP 5** 표시
- 최고 기록 갱신 시 알림
- 최근 20회 기록을 타수 추이 그래프(SVG)로 확인
- 기록 초기화 버튼 제공

### 설정 (⚙ 또는 `Esc`)

| 항목 | 선택지 |
| --- | --- |
| 테마 | 라이트 / 다크 / 세피아 (기본값은 시스템 설정을 따름) |
| 강조색 | 5가지 |
| 글자 크기 | 작게 / 보통 / 크게 |
| 언어 | 한국어 / English (인터페이스) |
| 효과음 | 틱 / 부드럽게 / 키보드 / 버블 / 끄기 (Web Audio API로 합성) |
| 오타 시 진행 막기 | 켜기 / 끄기 — 켜면 틀린 글자에서 멈춥니다 |

## 단축키

| 키 | 동작 |
| --- | --- |
| 아무 키 | 입력 시작 |
| `Tab` | 같은 글 다시하기 |
| `Enter` | 다음 문장으로 넘어가기 |
| `Esc` | 설정 열기/닫기 |

화면의 아무 곳이나 누르면 입력창에 포커스가 돌아옵니다.

## 구현 메모

- **한글 IME 조합 처리**: 조합 중인 마지막 글자는 판정을 보류하고, 확정된 글자만 정오 판정합니다.
- **붙여넣기·드래그 앤 드롭 차단**으로 부정 입력을 막습니다.
- **캐럿 애니메이션**: 줄이 바뀔 때는 대각선 이동 없이 바로 이동하며, 입력 중에는 깜빡임을 멈춥니다.
- **저장소**: 설정과 기록은 브라우저 `localStorage`에 저장됩니다 (저장 실패 시에도 앱은 정상 동작).

  | 키 | 내용 |
  | --- | --- |
  | `typing.cfg.v1` | 설정 |
  | `typing.hist.v1` | 최근 20회 기록 |
  | `typing.best.v1` | 최고 타수 |

## 커스터마이징

`<script>` 상단의 데이터 배열을 수정하면 연습 문장과 단어를 바꿀 수 있습니다.

| 상수 | 용도 |
| --- | --- |
| `KO` / `EN` | 한글 / 영어 문장 목록 |
| `WK` / `WE` | 한글 / 영어 단어 목록 |
| `ACCS` | 강조색 팔레트 |
| `I18N` | 인터페이스 문구 (언어 추가 시 여기에 항목 추가) |
| `SND` | 효과음 프리셋 `[파형, 주파수, 길이, 볼륨, 피치 변화]` |

## 브라우저 지원

`localStorage`, `Web Audio API`, CSS 변수를 지원하는 최신 브라우저 (Chrome, Edge, Safari, Firefox)
